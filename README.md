# Statistical Analysis with SAS

## Project Overview
This project involves a deep-dive statistical analysis of [E-commerce Users]. I utilized SAS to perform data manipulation and advanced statistical modeling to validate [Purchases].

## 📈 Key Statistical Methods
* **Data Cleaning:** Used DATA steps and PROC SORT to prepare raw data for analysis.
* **Exploratory Data Analysis:** Generated descriptive statistics using `PROC MEANS` and `PROC FREQ`.
* **Modeling:** Performed [Binary Logistic Regression] using `PROC Logistic` to identify significant predictors.
